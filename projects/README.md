# Capstone Projects

You've learned the building blocks — now put them together! Each project is a
small, complete program that combines skills from across the course. For every
project you get:

- a **brief** (what to build and which skills you'll practise),
- a **`starter.py`** with TODOs to fill in, and
- a **`solution.py`** — one working version to compare against.

Try to build each one yourself from the brief before peeking at the solution.
There's no single "right" answer — if it works, you did it. 🎉

## The projects

| # | Project | Skills practised |
|---|---------|------------------|
| 1 | [Number Guessing Game](01-number-guessing-game/) | `random`, `while` loops, conditionals, `input` |
| 2 | [Mad Libs Story](02-mad-libs/) | `input`, f-strings, variables |
| 3 | [To-Do List](03-todo-list/) | lists, loops, functions, conditionals, `input` |

## How to run

From inside a project folder:

```bash
python starter.py     # your attempt
python solution.py    # the reference version
```

> These programs are interactive — type your answers when prompted. They also run
> in the [browser version](../web/) of the course.
